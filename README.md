# ElBotto — aplikacja/GUI

Repo dla GUI + pakowania (PySide6 + PyInstaller). Integruje się z silnikiem `elbo`.

## Roadmap GUI
- MVP: dashboard (saldo, pozycje), wykres OHLC + sygnały, logi, przyciski Start Backtest / Start Live / Stop.
- Setup: kreator pierwszego uruchomienia (klucze API, wybór presetów).
- Build: `scripts/package_win.py` generuje .exe.
